SSH 远程登录说明

当前需要使用两步登录
  1. 第一步：在本机登录 broker ssh -p 22 -i <本机 broker 私钥路径> root@ssh-portbroker.evoxrobot.com
  2. 第二步：在 broker 终端登录机器狗 ssh unitree@127.0.0.1 -p <设备列表中的 SSH 端口>
    端口见下方设备卡片

broker 私钥不属于机器狗 SSH 凭据；第二步使用机器狗账号 unitree。
