# CPU 明细弹窗

目标：点击顶部CPU框，查看当前占CPU最高的5个模块/进程及占用率。

采用现有深色弹窗样式，保留顶部整机总占用显示。弹窗按当前PID命名空间可见进程统计（正式部署中导航、定位、运控、录包和web共享一个运行容器），明确标注容器外进程不在列表内。占比按整机所有CPU总容量归一化，线程合计，不与单核100%的top默认口径混淆。共用进程的ROS组件不拆分为虚构独立模块。

实现：新增 `server/cpu_stats.py`，读取Linux /proc相隔约0.5秒的两次计数，按PID和启动时间匹配，排除进程退出/重用和不可读项。模块名优先ROS __node，再取Python脚本或可执行名，不返回完整命令行。共享短时缓存和采集中请求，避免多个页面重复扫描。采样放工作线程，不阻塞导航和WebSocket事件循环。GET `/api/system/cpu` 为只读入口。

前端：CPU框改为原生按钮；独立 `static/js/cpu-details.js` 使用现有scrim/modal样式。首次加载、加载失败、无权限/无进程、断线均明确提示，刷新失败不把旧榜单当实时。只在弹窗打开时串行轮询，每2秒一次；关闭取消请求与定时器，ESC/遮罩/按钮均可关闭，焦点回到CPU按钮。模拟页面显示明确标注的模拟数据。
