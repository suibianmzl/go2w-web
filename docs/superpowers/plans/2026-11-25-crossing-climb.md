# 强制跨越联动普通爬台模式

目标：既有强制跨越首边界同时请求climb并设置ObstaclesCritic=false；末边界、取消或失败请求rough并恢复true。循环每圈重复，区间内接续先恢复设置再导航。无跨越配置的普通任务不改变用户手动选择的模式。

用户追加要求：爬台模式与导航/定位/示教/姿态等功能正常共用，不再绑定开启页面、页面心跳或最长开启时长，也不因急停/趴下自动改变模式选择。普通急停停车、导航任务控制权和机器人安全规则仍然适用。用户明确确认“续约要保留”：保留现有2101后台5Hz续约及运控协议，不修改运控工程。

实现：复用set_climb和climb_off，不增加任务持有锁、运行中爬台模式拦截或静态模式确认门槛。模式选择成功表示请求已发送，实际策略及过渡状态仍从运控dual反馈显示。自动区间边界选择模式，期间允许用户手动切换。参数恢复与模式关闭分别尝试，任何一项报错都会记录且不继续自动任务。仅由任务触发过爬台时自动关闭，普通路线不会关闭用户选中的climb。

界面：普通模式开关不再弹出导航禁用确认框，不要求先站起，不显示倒计时；按钮选择依据网页模式选择，遥控器RB请求单独显示，不把点击“关”误发成开启。模式已选但运控反馈缺失时保留状态和关闭入口。
